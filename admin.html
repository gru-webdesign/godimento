GitHub ključ

Cenovnik se čuva kao fajl menu.json u repozitorijumu sajta. Za čuvanje je potreban ključ (token) koji važi samo za taj repozitorijum. Ključ ostaje sačuvan samo u ovom browseru.

  1. Otvori github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories, izaberi godimento
  3. Permissions, Repository permissions: Contents: Read and write
  4. Klikni Generate token, kopiraj ga i nalepi ovde
